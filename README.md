# Why Does Washington State See Hundreds of Vehicle Crashes Every Day? (Project 2)

## Description
Access the public site: [WA Crashes](https://jeffreychoiuw.github.io/WA-Crashes/)  
Data Source: [Washington State Department of Transportation](https://wsdot.wa.gov/about/transportation-data/crash-data)

For this data story publication, I used WSDOT Crash Data to explain the current issue with vehicle crashes in Washington and how people can help to decrease and prevent future deaths and injuries. All of my charts were created using the D3 JavaScript library and help from the D3 Graph Gallery code tutorials and examples, as well as our in-class work. Specifically for the WA County map, I used a GeoJSON file from [this GitHub repository](https://github.com/jake-low/covid-19-wa-data/blob/master/README.md) which originates from U.S. Census shapefiles. Each of the three charts has a separate dataset that was copied from the [WSDOT Crash Data Portal](https://remoteapps.wsdot.wa.gov/highwaysafety/collision/data/portal/public/). The index.html file contains most of the narrative text and overall format. The main.js file contains the code for the D3 charts. And the style.css file contains styling for the text and graphics. Comments separate and explain the code of each section.
